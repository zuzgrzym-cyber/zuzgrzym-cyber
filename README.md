## Moje Projekty

### 1. Gra generująca grafiki marblingowe (Internal Assessment – CS IB)
* **Opis:** Aplikacja stworzona w Pythonie jako projekt zaliczeniowy z informatyki IB. Generuje cyfrowe grafiki inspirowane tradycyjną techniką barwienia papieru na wodzie (marbling).
* **Technologie:** Python
* **Opis: ** Interaktywna aplikacja desktopowa stworzona w Pythonie, która symuluje tradycyjną, turecką sztukę zdobienia papieru marbling. Program powstaje z myślą o pani bibliotekarce, aby mogła tworzyć unikalne okładki książek i grafikę. Aplikacja pozwala na nanoszenie kropli farby, manipulowanie nimi za pomocą specjalnych narzędzi (grzebienie, linie rozciągające), a także posiada system cofania ruchów (`undo`) oraz wbudowaną galerię zapisanych prac.

* **Technologie:** Python (`pygame`, `os`) 

### 2. Strona internetowa dla firmy taty 
* **Opis:** Wielostronicowa, w pełni responsywna strona internetowa stworzona jako nowoczesna wizytówka (dla firmy mojego taty). Projekt obejmuje podstrony informacyjne, galerię oraz zaawansowany formularz rezerwacyjny ze zdalną obsługą wysyłania wiadomości (integracja z API `Web3Forms`) i walidacją danych w czasie rzeczywistym (`Just-Validate`). Całość została zaprojektowana w Figmie i ostylowana z użyciem zaawansowanych zapytań medialnych (`@media queries`).
